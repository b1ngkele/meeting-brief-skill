# 写作风格偏好

> 本文件记录用户对简报写作风格的增量偏好。SKILL.md 中的基线风格规则不在此重复。
> AI 在收到用户反馈后在此追加记录。

## 措辞规范

- 使用决策性用语：`会议要求`、`请...牵头`、`需...完成`、`后续...推进`
- 避免模糊表述：`可能`、`也许`、`大概`
- 人名使用正式姓名，不使用昵称（如"老胡"应写为"胡洪杰"）
- 截止日期使用具体日期格式（如"6月30日前"），不使用"近期"、"尽快"等模糊时间

## 格式偏好

- 同一主题下的多个要点合并为紧凑段落，避免过多子条目
- 领导班子例会简报应读起来像领导指示，而非逐项目状态汇报
- 次要事项（如团建、评定）归入"其他事项"，不单独列为主题
- 公司级会议纪要应贴合红头纪要模板：`会议内容`控制为1–2个公司级概括段，`会议要求`控制为3–5个统领性小标题，避免堆成长项目清单
- 公司级 markdown 不写入`督办`、`出席人员`、`主送`、`承办部门`；这些内容由模板保留，尤其要保持`督办`为表格而非普通段落
- 公司级 DOCX 交付前必须渲染检查红色标题、红色分隔线、页码、督办表格和尾页承办信息
